# ICVGIP-2026
MB𝑭 2-DK: Frequency Aware MRI-Based Brain Tumor Detection using Kolmogorov Arnold Networks
Brain tumors are abnormal growths of cells in the brain that can be life-threatening. So early and accurate identification of brain tumors from magnetic resonance imaging (MRI) is essential for timely clinical intervention; however, manual interpretation remains time-consuming and dependent on expert analysis. To address this challenge, we propose a multi-branch feature fusion that can extract the spatial as well as frequency-based (Wavelet) features using a customized convolutional neural network. Our approach employs an advanced wavelet-based feature extraction phase to capture detailed textural and edge information. After that, we propose a Kolmogorov-Arnold network for robust feature learning and classification.
